# Security reporting

Please report vulnerabilities privately to **headria@gmail.com** with the subject `Canopy security report`. Include the affected commit, a minimal reproduction, expected impact, and synthetic test data where possible.

Do not post credentials, private transcripts, user screenshots, or exploitable sensitive details in public issues. The project currently has no guaranteed response-time or long-term-support policy.

Canopy stores its library locally as plaintext. Use your Mac's account and disk protections for sensitive data. The project does not operate a cloud storage or account service.
